# Aadarsh Gupta — Personal Portfolio

A responsive, dark luxury portfolio built with React, Vite, Tailwind CSS, and Framer Motion. The hero orb and project artwork are CSS-based, so the visual design does not require a heavy 3D runtime.

## Run locally

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create the production build in `dist/`.

## Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React
